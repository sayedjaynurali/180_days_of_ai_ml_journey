# 180 Days of AI/ML Journey  

This repository documents my **180-day challenge** to transition into **AI/ML engineering**.  
It is structured to demonstrate consistency, technical growth, and applied problem-solving in both **classical ML** and **modern AI (Generative + Agentic AI)**.  

The repo is intended as a transparent showcase of learning, projects, and progress — serving as both a personal discipline tracker and a professional portfolio.  

---

## Objective  

- Build a strong foundation in **Python, algorithms, statistics, and machine learning fundamentals**.  
- Gain hands-on experience in **generative AI** (LLMs, prompt engineering, fine-tuning, applied projects).  
- Explore **agentic AI systems** including autonomous agents and RAG (retrieval-augmented generation).  
- Apply learning through structured projects that bridge theory with real-world applications.  
- Showcase discipline, growth, and readiness for AI/ML engineering roles.  

---

## Roadmap  

### **Phase 1 – Foundations (Days 1–60)**  
- Python for AI/ML  
- Data Structures & Algorithms  
- Probability, Statistics & Linear Algebra  
- Core ML Algorithms (Regression, Classification, Clustering, etc.)  

### **Phase 2 – Generative AI (Days 61–120)**  
- NLP & Transformer Models  
- Large Language Models (LLMs)  
- Prompt Engineering & Fine-Tuning  
- Building AI-Powered Applications  

### **Phase 3 – Agentic AI & Projects (Days 121–180)**  
- Autonomous AI Agents  
- Retrieval-Augmented Generation (RAG)  
- Deploying AI Models  
- Capstone Project (integrating foundations + GenAI + Agentic AI)
